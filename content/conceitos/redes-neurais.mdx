# Redes Neurais Artificiais

As redes neurais são sistemas de computação vagamente inspirados nas redes neurais biológicas que constituem os cérebros dos animais.

Observe no código fonte desta página (frontmatter no topo) que ela se conecta com `conceitos/deep-learning`. E a página de `introducao` se conecta com esta! Isso cria uma cadeia no seu grafo de conhecimento.
